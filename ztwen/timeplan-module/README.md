# EducConnect — module TimePlan

Contient les modèles `TimePlan` et `TimePlanSlot`, deux migrations tenant, un composant Livewire de gestion, une vue Blade Tailwind et un guide d'intégration.

Lire `docs/INSTALLATION.md` avant de copier les fichiers : l'intégration du guard directeur et le remplacement transactionnel de `ClasseSubjectOfSchoolYear::replaceTeacher()` doivent être adaptés au projet existant.
